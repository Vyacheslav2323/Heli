# PRODUCT

## Surface Type
Product application (operations tool UI).

## Product Name
Thin Client Composer

## Primary Users
Developers validating STT, GLB rendering, MobileSAM, and lightweight object tracking integration locally.

## Core Jobs
- Start and monitor module servers (STT, GLB viewer, MobileSAM).
- Visualize GLB scene as full-viewport background.
- Run click-to-segment overlays via MobileSAM.
- Capture text and voice chat inputs in one bottom dock.
- Start object tracking from chat (`track <object>`, `track <index>`, `stop tracking`) or click selection.

## Success Criteria
- All module health checks (STT, GLB, MobileSAM, tracker) visible with clear degraded/down alerts.
- Voice transcripts appear in chat when STT is active.
- Segmentation overlays render correctly on top of the GLB view.
- Tracking boxes update over time after text- or click-initiated acquisition.
